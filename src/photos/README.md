# Photos

Photos in each folder appear in that chapter automatically, in filename order.
The number at the start sets the order; the rest of the name becomes the caption
(`3-sindoor.jpg` is captioned "Sindoor"). Photos keep their own shape on the page.

| Folder         | Where it shows                               |
| -------------- | -------------------------------------------- |
| `before`       | Rajiv (1) and Neha (2) in "Before"           |
| `roka`         | 01 The roka                                  |
| `after-roka`   | 02 First meeting after the roka              |
| `engagement`   | 03 The engagement                            |
| `pre-wedding`  | 04 The pre-wedding shoot                     |
| `wedding`      | 05 The wedding                               |
| `karva-chauth` | 06 Karva Chauth                              |
| `diwali`       | 07 Diwali                                    |
| `udaipur`      | 08 Udaipur                                   |
| `now`          | 09 Right now (Valentine's Day 2026)          |
| `finale`       | The photo the particles become at the end    |

The untouched originals are kept in `photos-originals/` at the project root (not published).

Tips

- JPG, PNG or WebP, about 2000 px on the long side. iPhone HEIC photos need converting first
  (ask Claude to "process the photos").
- Videos: MP4, short, under about 10 MB.
- `finale`: one clear photo of the two of them. If it is a silhouette against a bright sky,
  put the word `silhouette` in the filename.
